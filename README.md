# Sistema de Controle Financeiro Pessoal
##### `AV02 - LINGUAGEM DE PROGRAMAÇÃO I - P2`

**Objetivo:**
> Desenvolver uma aplicação de console em Java para registrar e acompanhar receitas e despesas pessoais. O sistema deverá permitir cadastrar, consultar, alterar e excluir lançamentos financeiros, além de apresentar um resumo da movimentação. O objetivo é aplicar os conteúdos estudados na disciplina, demonstrando domínio de lógica de programação e conceitos iniciais de orientação a objetos.
